# Instructor Clarification: Weekly Live Reports

Recorded: November 14, 2026

Source: A course message from Professor Zhang supplied directly by Devashish Batra.

## Governing rules

1. Run the desk each week from Week 4 through Week 7 on a company that filed an earnings release or another SEC report during that weekly window.
2. Commit and push the report to the team GitHub repository within 24 hours of the filing's EDGAR Accepted time.
3. Use the pushed Git commit timestamp as the weekly record.
4. Do not upload a separate weekly report to Brightspace.
5. Starting with Checkpoint 3, the checkpoint upload lists the live record completed so far.
6. The weekly reports are not separately graded.
7. The reports are a project gate. Missing 1 week, such as Thanksgiving in Week 6, has no cost. Missing 2 weeks prevents the top project tier.
8. The final project uses the weekly runs for the audits, hit-rate table, and decision log.

The [project live-record page](https://cinderzhang.github.io/FIN67110-Fall2026/project.html#the-live-record) supplies the remaining details and dates.

## Week 4 application

- Window: Monday, November 9 through Sunday, November 15, 2026.
- Eligible event: an earnings release or another SEC report filed during the window.
- Deadline: 24 hours after the EDGAR Accepted time.
- Required proof: a pushed GitHub commit containing the report.
- Brightspace action: none for the weekly report itself.
