# Instructions for AI coding agents in this folder

- Explain work in short, direct sentences. Aim for about 80% of ASD-STE100 style.
- Keep one main claim per sentence. Prefer active voice.
- Preserve every number, condition, and hedge when rewriting. Never turn “may” into “did.”
- Treat financial values as claims that need a source, period, units, and filing reference.
- Never print, commit, or include secret values in logs, reports, screenshots, or responses.
- Ask before changing GitHub visibility or publishing user work.
